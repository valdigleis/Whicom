# Whicom

Whicom é um pequeno compilador para uma versão simplificada da clássica linguagem  [WHILE](https://www.cs.cmu.edu/~aldrich/courses/15-819O-13sp/resources/while-language.pdf), o compilador será sendo escrito usando técnicas de **análise preditiva recursiva** para a construção do Analisador Sintático (Parser).
